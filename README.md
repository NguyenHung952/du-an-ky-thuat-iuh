# Dự án kỹ thuật IUH

Repository lưu trữ tài liệu và file dự án kỹ thuật, tập trung vào thiết kế mạch số, điện tử và các nội dung thực hành tại IUH.

## Cấu trúc

```text
du-an-ky-thuat-iuh/
├── du-an/
│   └── DAKT_ĐHĐTVT18HL_NHÓM 1.zip
├── thiet-ke-mau/
│   └── File thiet ke dong ho so IC so Anode su dung thach anh 4M LDNam.rar
└── README.md
```

## Nội dung

- `du-an/`: file dự án kỹ thuật chính.
- `thiet-ke-mau/`: file thiết kế mạch/đồng hồ số tham khảo.

## Mục đích

Lưu trữ, phân loại và chia sẻ các file phục vụ học tập, thực hành và phát triển dự án kỹ thuật.

> Các file gốc được giữ nguyên nội dung; chỉ sắp xếp lại đường dẫn và chuẩn hóa README.
